# Security policy

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not disclose a security vulnerability in a public issue, discussion, pull request, or commit.

If private reporting is not enabled, contact a repository owner listed in [MAINTAINERS.md](MAINTAINERS.md) through GitHub and include a concise reproduction, affected versions, impact, and any suggested mitigation. Do not include credentials or real customer/cluster data.

## Supported versions

Security fixes are applied to the current `main` branch and the latest released chart/image version. Older releases may receive a fix only where the impact and maintenance cost warrant it.

## Security expectations

Please report exposed secrets, authentication or authorization bypasses, unsafe Kubernetes permissions, cross-organization data access, dependency vulnerabilities, and supply-chain concerns. Coordinated disclosure is expected after a fix or mitigation is available.
